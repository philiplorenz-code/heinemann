# Reiserichtlinie

Für Hotelübernachtungen auf Dienstreisen gilt eine Obergrenze von 150 Euro pro Nacht. Höhere Kosten müssen vor der Buchung durch die Führungskraft genehmigt werden.

Die Reise ist so zu planen, dass die Gesamtkosten angemessen bleiben. Bahnreisen in der zweiten Klasse sind der Standard; Flüge sind zulässig, wenn sie einen erheblichen Zeitgewinn bringen.

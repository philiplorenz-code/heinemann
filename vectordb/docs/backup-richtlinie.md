# Backup-Richtlinie

Produktivdaten werden täglich gesichert. Für kritische Systeme prüft das Betriebsteam monatlich anhand einer Wiederherstellung, ob Sicherungen lesbar und vollständig sind.

Ein erfolgreiches Backup ist keine Garantie für eine erfolgreiche Wiederherstellung. Der Wiederherstellungstest dokumentiert Dauer, Abweichungen und verantwortliche Personen.

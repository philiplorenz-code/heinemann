# Phishing-Notfallplan

Verdächtige E-Mails dürfen nicht beantwortet oder weitergeleitet werden. Mitarbeitende melden sie über die Schaltfläche „Phishing melden“ im Mailprogramm.

Wurden Zugangsdaten auf einer verdächtigen Seite eingegeben, ist das Passwort sofort im Self-Service-Portal zurückzusetzen. Danach informiert der Anwender den IT-Service-Desk, damit Sitzungen geprüft und beendet werden können.
